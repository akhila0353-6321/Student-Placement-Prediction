# Student-Placement-Prediction
My first machine learning project using a Decision Tree Classifier to predict student placement.
## About the Project
This is my first Machine Learning project, built using Python and Scikit-learn. The model predicts whether a student is likely to be placed based on academic performance, technical skills, projects, internships, certifications, and DSA score.

## Objective
To understand the basic Machine Learning workflow by building and training a classification model for student placement prediction.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm
**Decision Tree Classifier**

The model learns patterns from the training data and predicts the placement status of students.

## Features Used
- CGPA
- Skills
- Number of Projects
- Number of Internships
- Certifications
- DSA Score

## Project Workflow
1. Create a sample student dataset.
2. Convert the dataset into a Pandas DataFrame.
3. Select input features and the target variable.
4. Split the data into training and testing sets.
5. Train the Decision Tree Classifier.
6. Predict placement outcomes for test data.
7. Evaluate the model using accuracy score.
8. Predict the placement status of a new student.

## How to Run the Project

### 1. Clone the repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder
```bash
cd student-placement-prediction
```

### 3. Install the required libraries
```bash
pip install pandas scikit-learn notebook
```

### 4. Launch Jupyter Notebook
```bash
jupyter notebook
```

Open `MyProjectModel.ipynb` and run the cells in order.

## Dataset
This project uses a small, sample dataset created within the notebook for learning and demonstration purposes. It is not a real-world student placement dataset.

## Limitations
